Using this in Apple Motion

CSV is a data interchange file; this tool does not create Motion rotation keyframes. For two independent overlays, select a fixed frame rate and export both Motion lean text and Motion speed text (one value per frame). Lean displays absolute angle plus LEFT/RIGHT (STRAIGHT at zero); speed uses your selected mph or km/h units, which you can add as a static label in Motion. Add two File text generators, one per file. Select Constant speed, turn Random off, and set both generators to the same duration: exported row count divided by frame rate. Start both at the same point on the Motion timeline, accounting for video offset. Check the first, middle, and last values against the preview; frame-accurate timing in Motion has not been verified here.

Missing values appear as “—”. Estimated values carry an “EST” label; peak-scaled estimates carry “CAL EST”. For an animated gauge or bike rotation, CSV needs a separate conversion or plugin; it is not a direct keyframe import.

How the data is interpreted

Recognizes explicit leanAngle, lean_angle and lean-angle point extensions as degrees. Other fields, generic roll values, and unknown units are not silently interpreted. ¹ Recorded signs are preserved as supplied; verify the device convention before using them. Estimates use positive right and negative left.

Known peaks multiply each side of the GPS lean curve by known peak ÷ full-ride GPS peak. Matching the maxima does not validate the intervening lean angles or their timing. Missing intervals remain blank. CSV includes the original GPS lean and entered peaks so the adjustment is traceable. Use peaks from the same complete ride, not a different trip or a trimmed clip.

Experimental GPS lean uses atan(speed × heading change per second / 9.80665), with a 3-point position window on each side. It assumes a steady, coordinated turn on level ground. GPS noise, banking, rider position and transients can make it inaccurate. Estimates are omitted below 3 m/s, across segment boundaries, gaps over 5 seconds, and at track edges. Frame exports linearly interpolate only within valid intervals of at most 5 seconds, never across segments or missing values. Higher frame rates do not add sensor detail.

All parsing, charts and downloads run in your browser. No ride files are sent to a server or saved between visits.
